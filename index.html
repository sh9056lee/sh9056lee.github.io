📚

문제집 찾기와 나의 책장

학년·과목·출판사로 좁혀 보고, 책 뒤 바코드만 비추면 바로 찾아요.

  • 바코드가 닳았다면 표지를 찍어 검색
  • 난이도·구성 같은 책의 특징을 한눈에
  • 예정 · 풀고 있음 · 완료로 진도 표시
  • 자녀가 여럿이면 학습자별로 책장을 따로
📝

찍어 두면 정리되는 오답노트

틀린 문제를 사진으로 남기면 단원별 폴더로 저절로 정리돼요.

  • 필요한 부분만 잘라내고, 적어 둔 풀이는 가리기
  • 지문이 긴 문제는 지문 한 장에 여러 문항을 묶기
  • 틀린 이유를 남겨 두면 약한 곳이 보여요
🔁

잊어버릴 때쯤 다시, 복습 카드

망각곡선에 맞춰 다시 볼 때가 된 문제를 알려줘요.

  • 카드를 넘기며 맞았는지 틀렸는지만 표시
  • 다음 복습 날짜는 자동으로
  • 연속으로 맞히면 '극복한 문제'로 졸업
🖨️

종이에 다시 풀기, PDF 내보내기

고른 오답을 시험지처럼 모아 인쇄해요.

  • 한 쪽에 넣을 문항 수와 순서를 직접
  • 다시 풀기용 · 복습용(메모 함께) 선택
  • 인쇄될 모습을 미리 보고 확인

📱

기기에 저장

오답 사진은 휴대폰의 [문서 › 문제집도감] 폴더에 저장되고, 서버로 보내지 않아요.

🔒

운영자도 볼 수 없어요

사진이 서버에 없으니 운영자가 열어볼 방법이 없어요. 앱을 지워도 폴더의 사진은 그대로 남아요.

🔍

표지 검색할 때만

표지를 찍어 책을 찾을 때만 제목 인식을 위해 그 표지 사진이 전송돼요.
